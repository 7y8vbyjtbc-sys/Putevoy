# Генератор путевых листов

Создаёт путевой лист на следующий месяц по листу за прошлый месяц: переносит
постоянные данные и одометр, раскладывает поездки по будням так, чтобы расход
по формуле шаблона совпал с выданными литрами до сотых.

## Файлы
- `putevoy_gui.py` — окно программы (перетаскивание файлов).
- `putevoy.py` — консольная версия.
- `putevoy_core.py` — вся логика и встроенная таблица расстояний.
- `shops.json` — справочник: магазин → адрес. Должен лежать рядом с программой.

## Как считаются расстояния
Офлайн, по населённому пункту в адресе: встроенная таблица расстояний по
дорогам между 45 пунктами Мурманской области («Мурманавтодор», kolamap.ru),
от центра до центра. Гаджиево, Высокий и Титан — оценка через соседний пункт.
Магазины в том же городе, что и офис, и ближе `min_km` (60 км) в поездки не попадают.
Время в пути — из расчёта 80 км/ч.

## Сборка exe (Windows 10/11)
Вариант 1 — на любом ПК с Windows: установить Python 3.12 (галочка «Add to PATH»),
запустить `build.bat`. Готовый файл: `dist\PutevyeListy.exe` + `dist\shops.json`.
Пользователям нужны только эти два файла, Python им не нужен.

Вариант 2 — без Python вообще: загрузить папку в репозиторий GitHub, открыть вкладку
Actions → «Build Windows exe» → скачать артефакт PutevyeListy.

## Обновить справочник
Перетащите в окно программы актуальный список магазинов (.xlsx со столбцами
«Магазин», «Тип», «Полный адрес») или нажмите «Обновить справочник из Excel…».
Магазины из `excluded` в shops.json в поездки не попадают.
